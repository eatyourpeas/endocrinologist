Useful tools for the paediatric endocrinologist

## What Is Included?

This if a Flutter project (v3.35.1) to create tools to be used by paediatric endocrinologists.

Mostly a work in progress but help is definitely welcome if people are interested.

Items that are built currently:

1. A glucose infusion rate calculator - it includes a list of milks (standard and specialist) with
   their g/100ml so that it can include enteral and parenteral glucose.
2. Steroid calculator - offers standard hydrocortisone doses against a body surface area, sick day
   doses and iv emergency doses.
3. Micropenis/Clitoral Length curve - normative values against age for children and neonates, for
   different ethnicities
4. Final Height predictors - currently support Bayley Pinneau, Tanner Whitehouse III, Roche Wainer
   Thissen
5. Body surface area calculator (includes the main types)

## Getting Started

1. Clone the repository - you will need the Android and iOS SDKs installed, as well as Flutter ('>
   =3.4.1 <4.0.0') and Dart.md. See how
   to [contribute](https://github.com/eatyourpeas/endocrinologist?tab=contributing-ov-file)
